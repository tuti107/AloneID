# ASHCOMBE HOUSE ― 闇にひとり

1924年、ニューイングランドの断崖に建つアシュコム邸。屋根裏で首を吊った当主の死の真相を追い、私立探偵エドガー・ヘイルはただひとり、嵐の夜の屋敷へ足を踏み入れる――。

『Alone in the Dark』(1992) に代表される、**固定カメラ × ポリゴンキャラクター**の古典的サバイバルホラーへのオマージュとして作った、ブラウザで遊べるゲームです。
画像・音声ファイルは一切使っておらず、テクスチャ、3Dモデル、効果音、音楽はすべてプログラムで生成しています。

## 遊び方

- `docs/index.html` をブラウザで開くだけで遊べます（単一の HTML ファイル）。
- GitHub Pages を `docs/` フォルダで有効にすれば、そのまま公開できます。
- PC（キーボード / ゲームパッド）とスマートフォン（タッチ操作）に対応しています。

### 操作

| 操作 | キーボード | ゲームパッド | タッチ |
| --- | --- | --- | --- |
| 移動 | 方向キー / WASD | 左スティック・十字キー | 左のスティック |
| 走る | Shift を押しながら移動 | スティックを大きく倒す | スティックを大きく倒す |
| アクション（調べる・開ける・取る・攻撃） | Space / Z / Enter | A / X | ［アクション］ |
| 持ち物 | I / Tab | Y | ［持物］ |
| メニュー | Esc | Start | ［≡］ |

- 移動は画面の向きが基準です（カメラが切り替わっても、押し続けている間は同じ方向へ歩き続けます）。設定で往年の「ラジコン操作」にも切り替えられます。
- ボタンはひとつだけ。近くに敵がいれば攻撃、目の前に調べられる物があれば調べる・開ける・取る、と状況に応じて自動で切り替わります（何をするかは画面下に表示されます）。
- 素手の攻撃は連打でパンチ → キック。武器は持ち物画面で装備します。
- 家具に向かって歩き続けると、押して動かせるものがあります。
- 物陰に隠れて見えないときは、主人公の輪郭が透けて表示されます。カメラは主人公が見える位置へ自動で切り替わります。
- 本やメモは持ち物画面の「読む」でいつでも読み返せます。……ただし、読むべきでない本もあります。
- セーブはメニューからいつでも（3スロット、ブラウザ内に保存）。力尽きても「最後の部屋からやり直す」で再開できます。

行き詰まったら [攻略メモ（ネタバレ注意）](docs/WALKTHROUGH.md) をどうぞ。

## 特徴

- 低解像度レンダリング（320×240 / 640×480）＋ 順序ディザリングによる VGA 風の画作り
- 部屋ごとに配置した固定カメラ。主人公が画面外や物陰に入ると、見える位置のカメラへ自動で切り替え
- 関節つきローポリゴン人形と手続き型アニメーション（歩行・走行・攻撃・被弾・死亡など）
- 11 の部屋、謎解き、呪われた本、ゾンビ化した使用人、晩餐を続ける亡霊、地下の怪物
- 雨音・雷鳴・きしむ床・怪物の唸り声・ワルツ・ボス戦の音楽まで、すべて WebAudio で合成

## 開発

```sh
npm install
npm run build     # docs/index.html（すべて同梱した単一 HTML）と dist/artifact.html を生成
npm run dev       # ミニファイなしの dist/index.html を生成
npm run watch     # ソース変更を監視して再ビルド
```

`dist/artifact.html` は claude.ai の Artifact 用で、three.js をバージョン固定の CDN から読み込みます。
`docs/index.html?room=hall` のように URL パラメータを付けると、タイトルを飛ばしてその部屋から始められます（デバッグ用）。

```
src/
  engine/   描画（ポストエフェクト）、入力、当たり判定、経路探索、固定カメラ、テクスチャ生成、音声合成
  game/     ゲーム本体、プレイヤー、怪物、アイテム、UI、テキスト、キャラクター、家具
  game/rooms/  各部屋の構築とイベント
```

依存ライブラリは [three.js](https://threejs.org/)（ビルド時に同梱）と、ビルド用の esbuild のみです。
