## 1. 目的

- 『Alone in the Dark』(1992) 風の、固定カメラ × ローポリゴンのサバイバルホラー「ASHCOMBE HOUSE ― 闇にひとり」をブラウザで作り、遊べる品質に磨く。
- 素材ファイルは使わず、テクスチャ・家具・人物・アニメーション・音（WebAudio）まですべてコードで生成する。
- 二幕構成・24 部屋・エンディング 3 種（真＝dawn / ember / tide）まで最後まで遊べる。物語と部屋の計画は `docs/EXPANSION_PLAN.md`、攻略は `docs/WALKTHROUGH.md`。
- ユーザーは iPhone の Claude アプリで、claude.ai の Artifact として縦持ちで遊んでいる。不具合や不満はスクリーンショット付きで届く。

## 4. 決めたことと理由

- **カメラ**（`src/engine/camera.js`）:
  - 部屋ごとの手置きの Shot（zone・priority）を基本にし、主人公が映っているかを `evaluate`（3 点の vis / frame / size）で判定する。
  - 映らなければ、最良の Shot → 四隅の自動カメラ → 追従カメラの順に切り替える。昔ながらの「カット」は保つ。
  - `Shot.when` は、条件が立っている間だけ使うショット。最後の脱出で、来た道を戻るときに出口の方を向くカメラに使っている。
- **操作**（`player.js`）: カメラ基準。スティックを同じ向きに倒している間は、カットが変わっても元の向きを保つ（カットで逆走しないため）。
- **当たり判定と見た目**:
  - 積み岩（`rockGeo` の半径は最大 1.25 倍まで膨らむ）は、`RoomKit.clearOf` で壁の当たり判定の外へ下げる。主人公が岩の中に立てないようにするため。
  - 壁は箱のまま滑らかに保つ。岩ごとの当たり判定にすると凹みに引っかかるので使わない。
  - 祭殿の岩は影を落とさないので、`userData.occlude` でカメラの遮蔽物として扱う。
- **段差の禁止**: 壁沿いに数 cm 出っ張る箱は、体を止めてしまう。第1幕の洞窟のトンネル脇と納骨堂の隧道は面を揃えた。`tools/checks/lips.cjs` で探せる。
- **最後の脱出**（祭殿 → 潮の洞窟 → 納骨堂 → 墓地、120 秒）:
  - 各部屋に、脱出中だけの「出口を向く」カメラ（`outIsland`・`outShelf`・`outEast`・`outNorth`・`outDoor`）を置いた。
  - 出口の灯り（祭殿の水路口の青白い光、洞窟の石段の灯り、納骨堂の扉のランプ）は `setup` で点ける。部屋は使い回されるため。
  - 入室時に行き先を一言表示する。
- **船長エゼキエル**: 打撃・銃では HP が尽きても膝をつくだけで、4.5 秒後に 4 割の HP で立つ。刃物（カトラス）でとどめを刺すと死ぬ。
  - 膝をついた船長の「斬る」（`priority` で机の海図より優先）は、自動でカトラスに持ち替えて斬る。
  - カトラスが無いときは「刃が要る」と出る。初めて膝をついたときに遺書の一節を出す。
- **セーブ**（`src/engine/store.js`）: localStorage と、Artifact の `db`（`data/users/<uid>`）の両方に置き、後勝ちで同期する。扉を通るたびにオートセーブ（「つづきから」の「オート」）。iPhone のアプリが Web ストレージを忘れることがあるため。
- **メニュー**: スティックやキーを倒しっぱなしにするとカーソルが送られる（0.38 秒後から 0.11 秒ごと）。
- **床の高さ**: 1.3 m 以上上下の階にある物は調べられない（塔の井戸の底から踊り場のパネルに届いていた）。
- **リリースビルドの分け方**: ソースのコミットの後に「Release build: …」で `docs/index.html` を入れる。

## 5. 試して駄目だったこと・つまずき

- 地下室の棚を途中まで押したところで道が開くように（閾値 0.65）したら、第1幕の洪水の脱出が壊れた（棚が入口に重なった）。1.45 に戻し、隙間を塞ぐ当たり判定を足した。
- ブラウザの確認を通しプレイと並べて走らせると、CPU の取り合いで塔の上りや洪水の脱出が偽の FAIL になる。必ず 1 本ずつ。
- `pkill -f <文字列>` は、その文字列を含む自分のシェルまで殺す。
- `page.evaluate` で、ゲーム側の Promise（`readDoc`・`goTo` など）を返すと待ち続けて固まる。返さない。
- 部屋を `build` だけで変えても、使い回された部屋には反映されない（`setup` に書く）。
- 作り済みの潮の洞窟で `flags.plankDown` を立てても、昇降梯子は下りない（キャプスタン `capstan` を回す）。
- 洪水の脱出で、ボットが「西へ真っすぐ」歩くとトンネル脇の段差で止まった。段差を直し、ボットは経路に沿ってカメラ基準で歩く `walkTo` に変えた。
- コミット `35631ad` のメッセージには、1 つ前の `54737ea` に入った脱出の灯りの話も混じっている。直すには force push が要り、自動モードで拒否された。今の決まりでもしない。
