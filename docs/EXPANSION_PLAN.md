方針は次の三つです。

1. **今の屋敷はそのまま「第一幕」として生かし、物語の後半「第二幕」を足す。** 今の洞窟の決戦は、物語の折り返し点（偽りの勝利）に変える。
2. **新しい部屋で、すでにゲームに出てくる「謎のまま放置された手がかり」を回収する。** たとえば、ホールの海水が滴る外套、名札を削られた老人の肖像画、誰が灯したのか分からない書斎と屋根裏の火、甲冑から感じる視線、タイトル画面で消える塔の灯り。
3. **タイトル画面に映る館の外観（東の塔、裏の庭、車）と地図を一致させる。**

## 2. 物語

### 2.1 今の物語（第一幕）

一九二四年冬。屋敷の主サイラスが屋根裏で首を吊り、娘のクララが私立探偵エドガーに調査を依頼する。

エドガーは屋敷を探るうちに、曽祖父エゼキエルが南洋の島から盗んできた「ウル＝タガ」の像のことを知る。日記や手紙をたどって星の石を手に入れ、地下洞窟の祭壇で像を封じて火を投じる。

### 2.2 追加する物語の柱

1. **「この火では足りない」（第一幕の結末の変更）**
   - 星の石で怪物は封じられるが、投げたランプの火は潮に呑まれて消える。
   - 島の教えにある「聖なる炎」は、ただの火ではなかった。洞窟は水に沈み、エドガーは時間制限のなかで脱出する（今の脱出演出を生かす）。
2. **クララの到着と失踪（第二幕の動機）**
   - 玄関ホールにたどり着いたとき、正面玄関が開き、ボストンにいるはずのクララが駆け込んでくる。「昨夜、父から電話があったんです」。
   - 直後に床から黒い潮が噴き上がり、クララは地の底へ引きずり込まれる。この像を目覚めさせる鍵は、アシュコム家の血だった。
3. **塔の「消えない火」**
   - エゼキエルは像と一緒に島の聖油も持ち帰り、塔の灯室でその火を百二十年燃やし続けて、神を眠らせていた。
   - 火の番をしていたのは執事のハーロウ。主が死んで「命じられる者」がいなくなった夜、火は消えた。オープニングで塔の灯りが消えるのは、この瞬間。
   - 「清めの炎」とは、この火のことになる。
4. **トマス（クララの弟）**
   - 一九一二年、六歳のとき、地下の潮に呑まれて死んだ。エレノアが星の石を隠した本当の理由。
   - 封じられていた子供部屋に幽霊として現れ、エドガーを導く。
5. **ジョナ・アシュコム（名札を削られた肖像画の老人）**
   - エゼキエルの息子。一八三〇年代に像を焼こうとして果たせず、一族の記録から名を消された。
   - 礼拝堂を建てたのは彼で、礼拝堂と納骨堂に「消えない火」と「もう一つの星の石」の記録を残している。
6. **黒鴎号の乗組員とエゼキエルの末路**
   - 一八〇二年の嵐の夜に失踪したエゼキエルは、洞窟の奥に隠した黒鴎号の残骸で、神の下僕となって生きている。島の星の石はもともと一対で、もう一つは彼が持っている。
   - 夜ごと屋敷を歩く溺れた水夫たちが、第二幕の主な敵「潮の下僕」。ホールの濡れた外套は航海士のもの。

### 2.3 第二幕のあらすじ

1. **目覚め:** 気を失っていたエドガーが目を覚ますと、屋敷は様変わりしている。
   - 床は浸水し、壁から海水が染み出し、潮の下僕がうろついている。
   - 地下室と洞窟は水没していて、もう進めない。
2. **進む道を探す:** 食堂の奥と厨房の裏口が、地震で開いている。ランプは洞窟で失った。
3. **西翼:** 肖像画の回廊、礼拝堂、温室。ジョナの記録から「消えない火」の秘密を知り、礼拝堂で聖油を手に入れる。
4. **東翼と塔:** 使用人棟でハーロウの鍵束を手に入れ、ボイラーを動かして塔の扉を開ける。灯室で聖油を注いで火を灯すと、光が海を掃き、潮が引いていく。その火を嵐のランタンに移して持ち出す（第二幕の明かり）。
5. **子供部屋:** トマスのオルゴールを鳴らすと、トマスが納骨堂の鍵をくれる。
6. **墓地と納骨堂:** 嵐の墓地から納骨堂へ降りる。潮が引いたので、海へ続く隧道を進める。
7. **潮の洞窟:** 黒鴎号の残骸でエゼキエル船長と戦い、もう一つの星の石と銛撃ち銃を手に入れる。
8. **深淵の祭殿:** クララが祭壇に捕らわれ、ウル＝タガの本体が目を覚ます。二つの星の石で封じ、消えない火を投じて焼く。
9. **脱出:** 崩れる洞窟から、クララを連れて時間内に地上へ逃れる。

### 2.4 エンディング（3 種）

| | 条件 | 内容 |
|---|---|---|
| 真エンド「夜明け」 | クララを救う＋トマスの舟を墓に供えた（寄り道） | 最終戦でエレノアとトマスの魂が怪物を押しとどめる。夜明け、燃え落ちる屋敷を二人で見送る |
| 通常エンド「残り火」 | クララを救う | 同じく脱出するが、夜ごとクララは子供の声を聞く |
| バッドエンド「潮騒」 | 脱出の時間切れでクララとはぐれる | 夜明けの断崖にエドガーひとり。波がクララの名を呼ぶ |

今ある死亡演出（正面玄関の闇、影の書）はそのまま残します。

つながりの要点です。
- **西翼:** 食堂の西の扉 → 肖像画の回廊 → 北の礼拝堂、南の温室 → 温室の庭口から墓地 → 墓地の地下に納骨堂 → 海への隧道。
- **東翼:** 厨房の裏口 → 使用人棟 → 階段を下りてボイラー室、奥の扉から塔の階段室。
- **塔:** 階段室の 2 階の踊り場に主寝室へ抜ける隠し扉があり、塔の側から開けると近道になる（バイオハザード風の回り道の短縮）。
- **地下:** 納骨堂 → 潮の洞窟と黒鴎号 → 深淵の祭殿。祭殿は第一幕の地下洞窟の真下にあたり、水没した洞窟と水路でつながっている。

## 5. 進行表

**第一幕**（今とほぼ同じ。変わるのは最後だけ）

```
屋根裏 → 二階廊下 → 書斎・浴室・主寝室 → 玄関ホール（大時計）
→ 厨房（油とマッチ）→ 食堂（レコード）→ 音楽室（星の石）
→ 地下室 → 地下洞窟（封印、だが火は消える）→ 脱出
→ 玄関ホール：クララ到着、さらわれる ＝ 第一幕 終
```

**第二幕**

```
目覚め（ランプなし、浸水した屋敷）
 ├─ 西：食堂 → 回廊 ──（屋根裏でジョナのカンバス）── 礼拝堂 → 聖油
 │            └→ 温室：水門 → オルゴールの鍵・帆船／寄生植物 → 庭口の鍵
 ├─ 東：厨房 → 使用人棟 → 貯蔵室 → ハーロウの鍵束
 │            └→ ボイラー室：三つの弁 → 塔の扉が開く
 ├─ 塔：階段室（嵐のランタン）→ 灯室：聖油＋マッチ → 消えない火
 │            （潮が引き、納骨堂の隧道が通れるようになる）
 ├─ 2 階：子供部屋：オルゴールの鍵 → トマス → 納骨堂の鍵
 ├─ 庭口 → 墓地 →（寄り道：帆船をトマスの墓へ）→ 納骨堂（カトラス）
 └─ 隧道 → 潮の洞窟：黒鴎号・エゼキエル戦 → 海の星の石・銛撃ち銃
      → 深淵の祭殿：最終戦 → クララと脱出 → エンディング
```

西と東は、どちらから進めてもかまいません。必ず通るのは、聖油と鍵束を両方そろえて塔の火を灯すことと、納骨堂の鍵を手に入れることです。

## 7. 今ある部分の変更

- **地下洞窟:** 星の石で封じたあと、火が潮に呑まれる演出に変える。脱出の時間制限は今のまま使う。
- **玄関ホール:**
  - クララが来てさらわれる場面を足す。正面玄関の闇の演出を「逆向き」に使う。
  - 第二幕では浸水し、甲冑が動き出す。
- **食堂:** 第二幕は亡霊が消え、倒れた椅子だけが残る。西の壁に回廊への扉（第一幕は開かない）。
- **厨房:** 裏口（第一幕は「内側から針金で縛られている」）が第二幕で開く。
- **二階廊下:** 西端に板で封じた子供部屋の扉（第一幕は開かない）。第二幕では潮の下僕が歩き回る。
- **屋根裏:** 木箱にジョナのカンバス（第二幕で入手）。
- **手がかりの書き足し:** 第一幕の文書に第二幕の伏線を足す。たとえば、エレノアの手紙にトマスの名、系譜にジョナの項。
- **タイトル画面と予告編:** 塔の灯りが消える場面が、本編の伏線になる。

## 8. 実装の進め方

7 段階に分けます。各段階の終わりに、最初から最後まで遊べる状態にします。そのうえで次の確認をし、コミットして公開版を更新します。
- 自動の通しプレイ（今の攻略ボットを延長）
- カメラの総点検
- ポリゴンのちらつき点検

| 段階 | 内容 |
|---|---|
| 1. 基盤 | 第一幕・第二幕の管理、部屋の幕ごとの変化（浸水、照明、敵の配置）、セーブ形式の更新（古いセーブも読める）、地図画面、エンディング分岐の枠 |
| 2. 幕間 | 洞窟の結末の変更、クララ到着と失踪、第二幕の始まり（ホール・食堂・厨房の変化）、動く甲冑 |
| 3. 西翼 | 肖像画の回廊、礼拝堂、温室（屋根裏のカンバスを含む） |
