# 15 秒の実写風ティーザー

ゲームの画面ではなく、実写の告知映像のような 15 秒の予告です（1920×1080・24 fps・-16 LUFS）。絵と音は Runway で作り、`edit.py` で編集します。

| 時間 | 絵 | 文字・音 |
|---|---|---|
| 0.0–2.75 | 嵐の断崖に建つ屋敷、稲妻 | 「一九二四年、冬。／マサチューセッツ州　ブラックポート」、雷鳴 |
| 2.75–5.0 | ランタンを掲げ、背後を振り返るエドガー | |
| 5.0–6.4 | 地下の水から掴みかかる溺死者 | 水音とうめき |
| 6.4–9.7 | 胸に青い星の光るエゼキエル船長、カトラスを振り上げる | ささやき「あれを……火に、還せ。」と同じ文字 |
| 9.7–11.5 | 祭壇のクララの背後に、深淵からせり上がる神 | 咆哮 |
| 11.5–12.0 | ランタンの炎が燃え上がる | |
| 12.0–15.0 | ASHCOMBE HOUSE ― 闇にひとり ― | 音楽の一撃に合わせる |

## 作り方

1. Runway で静止画を作る（nano-banana-pro、16:9）。屋敷の絵は隅に出た文字を避けて切り抜き、神の口は描き直してから使う。
2. 静止画から 5 秒の動画にする（gen-4.5）。
3. 音楽（eleven-music-v2.5、15 秒ちょうど）、効果音、ささやき声（eleven_v3）を作る。
4. 素材を作業フォルダに集めて編集する。

```sh
python3 tools/teaser/edit.py <作業フォルダ>
```

作業フォルダの中身は `clips/`（6 本の動画）、`audio/`（音楽・効果音・声）、`fonts/`（しっぽり明朝 Bold・Medium と Cinzel、Google Fonts の SIL OFL）。各素材の Runway のタスク ID と、使ったプロンプトは `shots.json` にあります。

- 各カットの使う区間、文字の出入り、効果音の位置は `edit.py` の先頭の表で決めています。
- 音は、ささやき声の下で音楽を下げ（サイドチェーン）、全体を -16 LUFS に揃えて、ピークを抑えます。
- 必要なもの: Python 3（Pillow）と ffmpeg。

生成物（動画や音）はリポジトリに入れません。
